# Бот расписания колледжа сервиса и дизайна (ВВГУ) в Telegram

Telegram-бот, который показывает расписание, замены и ссылки на дистанционные
занятия групп, читая **открытую Google-таблицу** расписания. Вход в личный
кабинет и API колледжа не нужны — данные лежат в публичной таблице.

## Что умеет бот

| Команда | Что делает |
|---|---|
| `/start` | Приветствие |
| `/расписание ГРУППА [ДЕНЬ]` | Расписание группы на день |
| `/замены ГРУППА [ДЕНЬ]` | Замены группы на день |
| `/дистант ГРУППА` | Ссылка на дистанционное занятие группы |
| `/помощь` | Справка |

День недели можно вводить по-русски (`пн`, `вторник`), по-английски (`пт`),
порядковым номером (`3`) или выбрать кнопкой. Регистр и раскладка не важны.

Примеры:

```
/расписание СОСУ-24-1
/расписание СОСУ-24-1 Пт
/расписание СосУ-24-1 Среда
/замены СДЗН-25-1
/дистант СДЗН-26-1
```

## Как это работает

Бот скачивает открытую Google-таблицу целиком (диапазон экспорта `format=xlsx`),
разбирает листы:

- **ПН…СБ** — расписание по дням недели (строки — преподаватели, колонки — пары,
  группа + кабинет);
- **Замены Пн…Сб** — замены (группа, пара, снятое/назначенное занятие);
- **Дистанционное обучение** — ссылки на встречи групп.

Данные кэшируются на 30 минут (настраивается), чтобы не дёргать Google на каждое
сообщение.

## Установка и запуск

Требуется Python 3.10+.

1. Получите токен бота в Telegram через [@BotFather](https://t.me/BotFather)
   (команда `/newbot`).

2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Создайте файл `.env` в папке бота (по образцу `.env.example`) и впишите токен:

   ```
   BOT_TOKEN=123456789:AAx0x0x0x0...   # ваш токен от BotFather
   ```

   Либо задайте переменную окружения `BOT_TOKEN`.

4. Запустите:

   ```bash
   python bot.py
   ```

> **Важно.** Таблица должна оставаться доступной по публичной ссылке
> («Доступ по ссылке» → «Читатели» в настройках доступа Google Sheets), иначе бот
> не сможет её открыть.

## Структура файлов

```
vvgu_timetable_bot/
├── bot.py               # Telegram-бот (aiogram 3)
├── schedule_parser.py   # загрузка и разбор Google-таблицы + кэш
├── config.py            # настройки (токен, id таблицы)
├── requirements.txt
├── .env.example         # образец .env
└── _test_parser.py      # проверочный скрипт (не обязателен)
```

## Настройки (config.py / .env)

| Переменная | Значение по умолчанию | Назначение |
|---|---|---|
| `BOT_TOKEN` | — | Токен бота (обязателен) |
| `SPREADSHEET_ID` | `1rg2JJr3QK_…` | ID открытой Google-таблицы |
| `CACHE_TTL_SECONDS` | `1800` | Как часто перечитывать таблицу (сек) |
| `REQUEST_TIMEOUT` | `40` | Таймаут запроса к Google (сек) |
| `BOT_PROXY` | пусто | Прокси к Telegram API, если закрыт прямой доступ |

## Прокси к Telegram

Если из вашей сети `api.telegram.org` недоступен напрямую (бот падает с
`Request timeout error` при старте), задайте прокси в `.env`:

```
BOT_PROXY=http://127.0.0.1:8080
```

Поддерживаются форматы:
- `http://host:port`
- `http://user:password@host:port`
- `socks5://host:port` — требует установки `aiohttp-socks`:
  `pip install aiohttp-socks`

После изменения `.env` перезапустите бота.

## Ограничения

- В исходной таблице **нет названий предметов** в листах расписания — только
  преподаватель, группа и кабинет. Бот показывает то, что есть.
- Смена недель («верхняя/нижняя») в таблице обновляется вручную методистами.
  Бот работает с тем, что сейчас залито в таблицу.
